- Node.js standard library - Required for installation, uninstall, dependency checks, file copying, prompt handling, and generated script creation in `bin/install.js`.
- Bash - Required for the installed statusline command generated by `bin/install.js` and helper/provider scripts under `bin/`.

**Infrastructure:**
- `git` - Optional dependency for branch and dirty-state display; checked in `bin/install.js` and used by generated shell code inside `bin/install.js`.

- Linux `secret-tool` and `timeout` - Optional Anthropic token source via system keyring in `bin/providers/anthropic.sh`.
- `shasum` or `sha256sum` - Used to derive non-default Claude credential service names in `bin/providers/anthropic.sh`.
- npm registry tooling - `npx` is the documented install path in `README.md`; `.codex/gsd-core/bin/check-latest-version.cjs` also shells out through npm for GSD update checks.

## Configuration

**Environment:**
- CLI flags are parsed in `bin/install.js`: `--provider`, `--dir`, and `--uninstall`.
- Default install target is `~/.claude`; custom install targets are accepted through `--dir` in `bin/install.js`.
- Provider choices are `anthropic` and `zai`, selected by `--provider` or an interactive prompt in `bin/install.js`.
- Anthropic auth sources are `CLAUDE_CODE_OAUTH_TOKEN`, macOS Keychain, `${SCRIPT_DIR}/.credentials.json`, and Linux `secret-tool` in `bin/providers/anthropic.sh`.
- Z.AI auth sources are `${SCRIPT_DIR}/settings.json` key `.env.ANTHROPIC_AUTH_TOKEN` and `~/.chelper/config.yaml` key `api_key` in `bin/providers/zai.sh`.
- Generated runtime cache is `${SCRIPT_DIR}/statusline-cache.json` with a 60-second max age in generated shell code inside `bin/install.js`.
- `.env` files are not detected in the repository; secret-bearing runtime files are expected outside the repo or inside the user's Claude config directory.

- No TypeScript config: `tsconfig.json` is not detected.
